# Gatehouse v0.2.3 changes

Working release notes. Add completed changes and their verification here as v0.2.3 takes shape.

## Added

- **Editable SPDT relay coils.** Set the coil resistance, pull-in voltage, and release voltage in the relay's value editor. Blank fields use the rated coil voltage preset, so existing projects keep their current behavior. Custom settings are saved with the project. Release voltage must be lower than pull-in voltage.
- **Searchable diode library.** Choose from 33 commonly used presets in the separate Diode, Schottky, and Zener editors. The library includes switching diodes such as 1N4148 and 1N914, silicon rectifiers such as 1N4007 and UF4007, Schottkys such as 1N5819 and SS34, and 1 W Zeners such as 1N4733A and 1N4742A. Diode and Schottky presets fill in editable curve parameters and ratings. Zener presets set the nominal voltage in the existing 1 W model. Projects store the chosen values for offline use. The forward curves are approximations, with junction capacitance and reverse recovery outside the current model.

## Changed

- **Themed scrollbars.** Glass mode uses rounded, blue-gray scroll thumbs with a subtle rim and recessed tracks. Solid mode uses flat, opaque colors, and the browser handles scrollbars in forced-colors mode.

## Fixed

- **Transient solver recovery.** When a time step fails to converge, Gatehouse retries it with a shorter interval within the existing minimum step size and per-slice solve budget. This fixes a light transition in the AVT1476 dusk-switch circuit where the solver could advance with a failed result and display zero voltages.
- **Main website button.** Removed a visual streak under the web app button by adjusting its blur, hover shadow, and stacking order.
- **Part editor layout and motion.** Relay units stay on the same rows as their fields, including the coil voltage dropdown. The diode search results have a small gap below the search field, and the editor expands smoothly from the closed toolbar's width.
